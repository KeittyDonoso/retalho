# Retalhos

Editor de vídeo que roda no navegador, no computador e no celular.

## O que ele faz

- Abrir um vídeo (botão **Abrir vídeo** ou arrastando o arquivo)
- **Dividir** o vídeo onde está a agulha
- **Apagar** trechos
- **Texto** na tela (em cima, no meio ou embaixo)
- **Desfazer** e **Refazer**
- **Exportar** o vídeo final, gravado no próprio aparelho (MP4 ou WebM, conforme o navegador)

## Como editar o código

O código fica em `src/editor.html`. Depois de mudar, rode:

```sh
python3 build.py
```

Isso gera o `index.html` (a página do site) e o `retalho.html`.
